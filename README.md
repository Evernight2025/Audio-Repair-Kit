# 音频修复器 (Audio Repair Kit) 便携版

> 解压即用 · 本地处理 · 支持 Windows / macOS / Linux / Android

[English README](README_EN.md)

一款开箱即用的本地音频批量修复 / 增强工具。下载压缩包、解压、双击启动，即可在浏览器中批量处理音频：降噪、人声增强、音质提升、格式转换、音量调整、淡入淡出、空间环绕渲染…… 所有处理都在你的电脑本地完成，音频文件不会上传到任何服务器。

---

## 功能特性

- **批量处理**：添加单个文件 / 整个文件夹（递归扫描）/ 直接拖拽，可勾选移除、清空
- **60+ 主流音频格式**：mp3 / wav / flac / aac / m4a / ogg / opus / wma / ape / dsf / dts / ac3 等
- **降噪**：不处理 / 一般（轻微底噪电流声）/ 极致（重度噪声）
- **清晰人声**：人声频段 EQ 增强 + 动态压缩 + 咝声抑制
- **8 档输出音质**：原声 / CD 无损(44.1kHz 16bit) / HIRES 无损(96kHz 24bit) / 立体声 / 环绕声(5.1) / 杜比全景声(7.1 空间渲染) / 母带(192kHz 24bit) / 自定义(采样率+位深度)
- **输出格式转换**：FLAC / WAV / MP3 / AAC / OGG / Opus（多声道档位自动回退 FLAC）
- **音量 / 响度**：智能响度规范(-14 LUFS) 或 ±3 / ±6 dB 手动增益
- **淡入淡出**：0.5 / 1 / 2 / 3 秒
- **文件命名方式**：自动命名（追加处理标记）/ 原名称 / 自定义（多文件自动编号）
- **列表筛选**：全部 / 待处理 / 已完成 / 错误 四种视图
- **错误自动弹窗**：失败时弹出报错信息与错误日志，支持一键复制
- **实时进度**：每个文件独立进度条 + 处理速度 + 总进度 + 预计剩余时间
- **四语言界面**：中文(简体) / 中文(繁體) / English / 日本語，一键切换并自动记忆
- **跨平台**：Windows / macOS / Linux / Android(Termux)，页面自动适配手机屏幕
- **防闪退**：断线自动重连、任务不中断、误关页面有确认提示

## 系统要求

| 平台 | 说明 |
| --- | --- |
| Windows | 7 及以上（推荐 10/11），双击 bat 启动 |
| macOS | 10.13+，终端执行 sh 启动 |
| Linux | glibc 环境（绝大多数发行版），终端执行 sh 启动 |
| Android | 安装 Termux 后执行 sh 启动 |

首次运行会自动下载运行环境（Python 便携版约 11MB、FFmpeg 引擎约 30~170MB），下载失败自动重试，仅首次需要联网。

## 快速开始

### Windows
1. 解压压缩包到任意位置
2. 双击 `启动音频修复器.bat`
3. 浏览器自动打开操作页面（默认 http://127.0.0.1:8765）

### macOS / Linux
```bash
bash 启动音频修复器.sh
```
缺少 Python3 / FFmpeg 时会自动尝试用 brew / apt / dnf / apk 安装。

### Android (Termux)
```bash
bash 启动音频修复器.sh
```
脚本自动执行 `pkg install python` 与 `pkg install ffmpeg`，然后在手机浏览器访问终端提示的网址。

## 使用示例

添加文件 → 选择处理选项 → 点击「开始处理」：

```
降噪：一般（推荐）
清晰人声：不处理 / 加重人声
输出音质：HIRES 无损（默认）
输出格式：跟随音质档位（无损）
音量：智能响度规范（-14 LUFS）
命名：自动命名 / 原名称 / 自定义
保存路径：留空 = 保存到源文件夹
```

处理完成后点击「打开输出文件夹」直接定位结果，所有日志（滤镜链、完整命令、耗时）在底部实时滚动。

## 输出说明

- 无损档位默认输出 FLAC；自定义 32bit 时输出 WAV；原声档位保持源格式（MP3 320k / AAC 320k / PCM 等）
- 环绕声 / 全景声档位选择有损格式时自动回退 FLAC，以保留全部声道信息
- 文件名自动避开重名，不会覆盖源文件

### 关于「杜比全景声」的诚实说明

真正的杜比全景声（Dolby Atmos）编码需要杜比官方授权工具。本工具的「杜比全景声」档位输出的是 **7.1 声床 + Haas 相位扩展的全景空间渲染**（FLAC 7.1 / 48kHz / 24bit），可获得沉浸式全景声场效果，但并非杜比官方 DD+/TrueHD 编码。

### 关于「母带音质」的说明

母带音质档位 = 192kHz / 24bit 高规格重采样 + EBU R128 响度规范（-14 LUFS / -1dB TP），在规格上接近或超越录音室母带；但无法凭空提升录音本身的音质缺陷。

## 技术架构

```
AudioRepairKit/
├── 启动音频修复器.bat        # Windows 启动器（自动装 Python/FFmpeg，带重试）
├── 启动音频修复器.sh         # macOS / Linux / Android 启动器
├── 使用说明.txt              # 完整使用文档
├── README.md / README_EN.md  # 项目说明（中/英）
├── app/
│   ├── server.py             # 纯 Python 标准库 HTTP 服务（零 pip 依赖）
│   └── www/index.html        # 单文件 Web 界面（四语言国际化）
├── runtime/                  # FFmpeg 引擎（首次运行自动安装，不入库）
└── app_data/                 # 上传暂存 / 默认输出 / 日志（不入库）
```

核心设计：

- **零 pip 依赖**：服务端仅用 Python 标准库（http.server / subprocess / zipfile / tarfile），保证便携
- **FFmpeg 滤镜链**：降噪(afftdn) → 人声(EQ+压缩+deesser) → 音量(loudnorm/volume) → 淡入淡出(afade) → 重采样(soxr) → 声道(pan/surround) → 响度限制(alimiter)
- **能力探测与降级**：启动时探测 soxr / surround / afftdn / loudnorm 等滤镜，不可用自动切换降级方案
- **全链路容错**：下载 5 次重试 + 备用通道、单文件失败自动重试、HTTP 层异常兜底、断线自动重连

## 隐私与安全

- 服务默认只监听 `127.0.0.1` 本机回环地址，不对外网开放
- 所有处理均在本地完成，音频不上传任何服务器
- 如需局域网访问：`python3 app/server.py --host 0.0.0.0`

## 常见问题

| 问题 | 解答 |
| --- | --- |
| 防火墙提示？ | 默认仅本机通信，勾选「允许」即可 |
| 杀毒软件报毒？ | bat 仅为启动脚本，ffmpeg 为官方开源构建，误报请添加信任 |
| Linux 引擎下载失败？ | 需要 glibc 环境；也可 `sudo apt install ffmpeg` 后点击引擎状态重试 |
| Termux 无法下载引擎？ | 必须用 `pkg install ffmpeg`（脚本会自动尝试） |
| 处理大文件慢？ | Hi-Res / 母带档需要高精度重采样，属正常现象 |
